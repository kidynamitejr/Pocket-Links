# Pocket Links

Nine holes of golf at Hollow Creek (par 36), built for your phone.

**Play:** https://kidynamitejr.github.io/Pocket-Links/

On iPhone, open the link in Safari, tap **Share**, then **Add to Home Screen** to install it as an app. It works offline after the first visit.

## How to play

1. Tap the map to aim. The club picks itself for the distance, or change it with the arrows.
2. On the swing pad, pull down to set power, then swipe straight back up to hit.
3. Swipe up to the right and the ball slices right. Swipe up to the left and it hooks left.

## Editing the game

The game source is `source/game.html`. After editing it, run `source/build.ps1` in PowerShell. It writes the installable files to `source/site/`. Copy those files to the top of this repo and push.
